# GPT's Gemini Guarder

这是 GPT Daddy 与 GPT Salad 的合并版本地插件。已注册市场 `gemini-guarder-local`，并安装 `gpts-gemini-guarder@gemini-guarder-local`。两个旧插件和旧市场入口已移除；壁纸与词库数据目录未删除。

## 当前功能

- Codex 桌面端：选中文本后显示“划词翻译 / 加入生词本 / 复制 / Google 搜索”；选区右键也显示同一菜单。翻译会把提示发送到当前 Codex 对话，使用当前会话模型。
- 词条先保存为独立 UTF-8 JSON 文件，位于当前账户的 `Documents/GPT Salad Vocabulary/entries`。无平台同步依赖。打包的 `scripts/vocab.py` 支持查看、编辑、逐义收藏、归档和 CSV/JSON 导出。
- GPT Daddy 壁纸与新设计悬浮面板。面板含 Gemini、壁纸库、生词本、主题与设置；原“首页”的播放与画面控制已移至“主题”。Gemini 栏在面板内直接显示 Chrome 打开的真实 Gemini 网页，沿用浏览器登录状态，不使用桌面快捷方式。网页填满 Gemini 栏余下空间；切换栏目或关闭面板时隐藏嵌入窗口，浏览器进程继续运行。用户将网页全屏或拖成独立窗口后，切换栏目不移动它。
- “主题”滑块拖动时立即预览，短暂停顿后自动保存；页面仅在相关栏目打开时刷新状态，壁纸目录按需读取。
- 生词本页有 Notion、Obsidian、OneNote 三个不同按钮。先填各自的目标地址；按钮仅打开地址，尚不执行同步。

## 已验证

- 2026-11-15：本地插件安装状态为 `installed, enabled`。
- 现有 Node 测试 30/30 通过；本地词库存取在隔离测试目录通过。
- 在真实 Codex 主页面读到新面板、选区菜单及三个目标按钮；合成的文本选区右键触发自定义菜单。
- 在真实 Codex 桌面窗口截图中确认 Gemini 网页与输入框填满 Guarder 的 Gemini 栏；切到“主题”后网页不再遮挡页面。滑块输入事件立即把不透明度设为 0.37，并自动保存到本地状态；测试后恢复原值 0.03。
- Win32 实测：嵌入窗口全屏后父窗口为 0，点击最小化后重新成为 Codex 面板子窗口；全屏时切到“主题”不影响全屏窗口，之后最小化会回到面板并保持隐藏，避免遮挡“主题”。
- Win32 实测：窗口离开停靠位置后自动成为独立窗口；此时切到“主题”仍保持可见。嵌入状态使用 `WS_EX_TOOLWINDOW`、去掉 `WS_EX_APPWINDOW` 与最小化样式，避免任务栏入口并禁用最小化系统命令。
- 尚未通过真实用户点击验证完整“发起翻译→模型回复”链路，也未向真实词库写入测试词条；外部平台按钮尚未配置用户目标。

Codex 进程需要已验证的本机 CDP 连接才能显示注入式菜单和悬浮面板。Gemini 嵌入使用 Windows 原生窗口附着，需要 Chrome 与用户的网页登录状态；它不依赖 Gemini 收费 API。插件本身不修改官方程序文件；当前会话已连接，后台服务已加载新版代码。其他应用与 ChatGPT Chat 视图不在本版取词范围。
